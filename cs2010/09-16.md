## Some history

- Our modern 7-bit ASCII character set was finalized in 1965.
- That gives us all the characters on a modern American keyboard.
- But how do we write "en båt".
- We use latin-1, which covers most European languages that use
the latin alphabet.
- There are a bunch of other alphabets:
  - Cyrillic alphabet
  - Greek
  - Arabic
  - Hebrew
  - ... at least 15 more alphabets/abduga
  - 20 * 40 = 800
- Broad categories of character sets:
  - Alphabets are one letter per sound.
  - Syllabaries are one letter per syllable.
  - Abduga's? are one letter per consonant-vowel pair
  - Stuff like chinese, with one symbol per word
  - The crazy thing the Koreans did
- First solution:
  - Each language (or Europe) got its own character set
  - Some character sets needed to be 16-bits per letter
- In 1987, people started on Unicode.
  - Idea: Every language in one unified character set.
  - Can this fit in 16 bits?
    - All common alphabets: 800 characters
    - Korean:
      - 51 base symbols, stuck together in groups of 3
        to make syllables
      - Combine into about 11,000 common characters
    - Chinese characters:
      - ~20k distinct characters
      - Chinese characters are used in Chinese, Japanese, and Korean
      - Extra fun: There are "chinese characters" that are only used
      in Japanese or Korean.
  - Sure, it fits in 16 bits.
- Before 1990, most software assumed 8 bits per character.
- In the 90's some software shipped assume 16 bits per character.
  - The programming language Java.
  - An obscure OS called Microsoft Windows (from Windows 95 onward)
- Unfortunately, people wanted more characters.
  - The assumption for 16 bits was only actively/widely used, modern
  writing systems.
  - At least one modern language got missed.
  - People really wanted to digitize historical documents.
  - Needed space for Egyptian heiroglyphs and stuff.
  - People wanted emojis. 🦞☃️
  - That doesn't fit in 16 bits
- The unicode consortium defined a character as a 32 (maybe 24) bit number.
  - To make this work, they defined variable-length encodings.
  - Windows / Java could store one character as one or two 16-bit numbers.
  - For backwards compatibility with systems still using 8 bits per character,
  an encoding (UTF-8) allowing 1, 2, 3, or 4 bytes was defined.
    - 1 byte character = ASCII
    - 2 byte character = Any alphabet
    - 3 byte character = Chinese / Japanese / Korean
    - 4 byte character = an emoji or rare / historical symbol
  - Text files frequently aren't just text, they're some sort of markup.

- If it's on disk, we call it a text file.
