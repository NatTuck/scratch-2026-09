
## More Security, Really This Time

### Cross-site request forgery (XSRF)

- Start on the attacker's fake website
- Follow a link/form to some real website, preferably with a POST
request that does something helpful to the attacker
- User has session cookies to real website, authentication succeeds

### Cross Site Scripting (XSS)

What if the comment on your MySpace page is:

<script id="x">
  myspace.myPage.post(document.getElementById('x').outerHTML);
</script>

Idea: Maybe we shouldn't let comments include script tags.

<?php
  for each comment c:
    echo("<pre>")
    echo(c.text)
    echo("</pre>")
?>

Solutions:

- Don't allow users to input arbitrary HTML and then show it on
your web page.
- Safe HTML is hard. Script tags are not okay. `<a href="javascript:...">` is
bad. <img src="javascript:alert('hello')">. <p style="...">
