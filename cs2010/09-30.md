
# LLMs, pt 2

Training sequence:

- Pick an archetecture and size (e.g dense 9B, delta-net linear attention
mechanism)
- Get enough training data, at least 20 tokens per weight (e.g. 180 GB of
text = about 10x the size of Wikipedia)
- Start with random weights
- A token is a word or symbol, e.g. "hello", "%".
  - Edge cases: "goat" might be a token, but "goats" might be two (goat + s
  suffix). "10" might be one token. "35792" is not one token.
- Repeat this process for all of our training data
  - Feed in a token, it predicts the next token (forward pass)
  - This token is wrong, and for each weight we can calculate which direction
  the weight was wrong in (by taking the derivative of the formula for the
  weight) (backpropagation)
  - Bump each model weight slightly in the direction towards more correct

This produces a "base" models. This just predicts next word of language, it
doesn't do chat.

"The capital of France is "... Paris

Professor Smith, an expert biologist, explained cell divisor as follows: "

Instruct model:

- After base model training, you can use that basic language "knowledge" to
build on.
- An instruct model is further trained to take turns.
  - First, there's a user start token and a user message.
  - Then, there's an assistant start token and an assistant message followed
  by a stop token.

Conversation might look like this:

```
|user> What is the capital of France?
|assistant> The capital of france is Paris.<|stop|>
```

When we send a message to an instruct model (which is how chat bots work):

```
|user> What is the capital of France?
|assistant> 
```

Fine tunes / additional post-training:

- Get the model to do other stuff, like:
- Handle tool calling
- Talk like a pirate

## Chatting with a Chatbot

The chat starts with the harness injecting a System message.

The models are trained specifically for system prompt adherence
over prompt adherence generally.

```
|system> You are {some model}. The time is {some time}. Do not
use tools to hack the US government. Do not produce any output
that would make Anthropic, Inc look bad or might be useful to
help anyone understand how a computer works in a way that would
be related to cybersecurity.
```

## A new key data format

We've seen:

- Text
- Markdown

New thing: JSON

JSON allows us to represent arbitrary structured data as text.

Simple types of data:

- Strings of text ("in quotes")
- Numbers (not in quotes, like 43)

Complex types of data:

- lists: `[1, 2, 3, 4]` or `[["hello", "there"], ["list in a list"]]`
- objects: `{"color": "red", "species": "red panda", "age": 7, "meals": [{...},
{...}]}`
