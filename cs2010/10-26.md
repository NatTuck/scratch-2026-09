
# 10-26: Programming

Our basic story:

- Computers store and transform data. So to use computers, we need to think
about using them to do that.
- Data at rest tends to live in files.
- We transform data by running programs that read files and write to (maybe new,
maybe the existing) files.

That's really simple if we already have a program that does the transformatoin
that we want. We just need to know what program to run.

The really cool thing about computers is that they can run *any* program, so if
we don't have the program we want we can make it.

## Lab This Afternoon

- You'll work with a partner.
- We'll be doing activities that help think about programming as
data transformations.

## Python / Idle

Python is extremely powerful, but weird.

- It's a dynamic, scripting type language.
- It supports the standard high level data structures:
  - `["lists", "of", "stuff"]`
  - `{"dictionaries": 3, "map": 4, "keys to values": 7}`
- Plan:
  - Build up our data as a combination of lists and dictionaries.
  - Write a function that transforms data in our input format
  to data in our output format.
  - Try not to get distracted by classes / objects.
  - List comprehensions are cool.
