
## Images for the Milk-V Duo S

**Milk-V Stock Image**

- Not intended to be a full Linux system.
- You build the image on a separate system - config changes
mean reflashing the sd / emmc.
- Everything can be made to work.

**Fishwaldo Image** (Google "fishwaldo milkv duos")

- Debian OS - you can ssh in and do stuff.
- Camera doesn't work
- Can load Ardino / RTOS images to second core at runtime.

**Scpcom Image**

- Debian OS based on Fishwaldo, more recent.
- Camera works, RTOS on second core doesn't (the device tree isn't even right)

**Armbian Image**

- Exists. Most recent and maintained.
