## Dense vs. MoE

- A dense model activates every weight for every input token.
- A Mixture of Experts model only activates some subset of experts for
each token.
  - Maybe you have a 122B-A10B model, so that's 122B total weights and
  only 10B weights activated per token.
  - You need RAM to store 122B weights.
  - But you only need memory bandwidth to transfer 10B per token.
  - Maybe we're split into 36 experts and activate three per token.
- Dense models are smarter for a given size. MoE models perform like
a dense model somewhere between the total and activated weight counts.

## Prompt processing vs token generation

When we send a request to an LLM, we send a prompt (the current message + the
whole conversation history) and then get back a response.

Processing happens in two phases:

- First the LLM needs to pre-process the whole prompt, computing with every
input token against every weight. This is limited by compute power.
- Then it computes the output tokens, one at a time, each token against
every weight. This is limited by memory bandwidth.

Prompt processing is important.

- Imagine we have a 100k token prompt and our prompt processing speed is
500 tok/s. How long before we start to get response tokens?
- 3.5 minutes
- That's not great for interactive conversation

Mechanism to speed up prompt processing: KV cache

- KV cache takes memory, typically the same memory that's used for weights.
- Models vary drastically in how efficent their KV cache is. Older models
might require 32kB per token. DeepSeek v4.1 flash requires 900 bytes/token.
  - That's 3.2GB of VRAM to cache a 100k token prompt
  - Modern models like to handle up to 1M tokens, so that'd be 32GB
    - Assume an average session uses half the window, thats 16GB

Example:

- We buy an AI server with 64GB of VRAM.
- We load Qwen 27B at 8bpw = 27GB (tweaked for 1M token cache)
- Each concurrent user (or session) needs 16GB of VRAM for KV cache
- How many users can we have? Two = 16 + 16 + 27 < 64.

- Nvidia 5090 has 32GB of RAM for $4000.
- Nvidia Pro 6000 has 96GB of RAM for $16000 and is a bit slower while
using about the same amount of power.
