
# Software Licensing

## Copyright

Anything a person writes or otherwise authors - software, a novel, a movie,
music, etc - is covered by copyright law.

In practice, copyright may restrict:

- Creating modified versions (derivative works).
- Distributing modified or unmodified copies.
- Any use that involves incidental copying.

By default, these actions are disallowed for anyone but the copyright holder.
The government has granted a legal monopoly for those actions.

Copyright is automatic - the copyright holder is the author or their employer -
and last more than 50 years. The common case is life of author + 70 years.

Effective all software for modern digital computers is covered, unless the
copyright holder specifically released it to the public domain.

## Copyright Licenses

In order to copy, modify, or distribute a work of authorship that's under
copyright (so any software), you need a license from the copyright holder.

A license lets you do some or all of the stuff covered by copyright, and
can impose restrictions on those activities. Copyright holders may charge
money for licenses, they may be time limited or otherwise restricted, etc.

Some software comes with a "clickwrap contract". That may or may not be
legally binding, but it's also likely your only copyright license.

If you're doing software engineering / game dev, this is important. Usually
individuals don't get sued for copyright infringement, but businesses do.
We need to make sure we have licenses for all the stuff we're using (software,
art assets, whatever).

## Kinds of License

### **Proprietary**

You cannot freely copy, modify, and redistribute this software. It's usage
is heavily restricted, and you need to ask permission to change how you
use it.

### **Open Source**

You can freely copy, modify and redistribute the software.

You have access to the source code.

Kinds of open source:

**Permissive**

Do what you want, as long as you distribute the license and copyright
notice with derivative works.

Common examples:

- BSD / MIT / X11 license - Pure, no unexpected extras.
- Apache 2.0 - Adds a clause to prevent patent aggression.
  - If you contribute code to a project that is covered by a patent
  that you hold, you won't sue any users of this software for that
  patent.

**Copyleft**

- GNU General Public License
  - There's a V2 and a V3, both in common use.
    - V3 requires that you be able to install modified versions on
    consumer hardware.
  - If you redistribute this software, the whole thing (including any
  modifications) must be under this license. With binaries, you must
  also distribute corresponding source code.
- GNU Affero General Public License
  - Adds a rule that if you host the software as a network service,
  you must offer corresponding source code to users.

**When do we care?**

- Our software
- Our dependencies

**How do you tell what license your dependencies use?**

- The license shows up in the package.json and LICENSE.md in
the software distribution.
- You can write a script to go look at all your dependencies.
