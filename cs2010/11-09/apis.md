## Programmer Interface

- Programmers can write computer programs.
  - Scripts are just a bunch of command line commands.
  - Or we can use a full fledged programming language.

Programming languages give you tools to transform data in memory.

Modern operating systems prevent programs from actually doing anything
themselves. That's for two reasons: Security (not clear what that means),
Reliability / Resource Sharing (can't have two programs fighting over the same
resources)

The operating system provides a programming interface to access
shared resources like hardware devices, files, the network, etc.

**Network APIs**

We can have programming interfaces that allow programs on one computer to
interface with programs on other computers.
