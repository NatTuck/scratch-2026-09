## Model Sizes

In lab last week, we ran Qwen 3.5 9B.

- That's 9B weights
- Each weight is naturally 16 bits = 2 bytes
  - Needed during training
- For deployment, we quantize the weights
  - 8 bits = good quality
  - 4 bits = okay quality

Where do we need to store weights:

- Optimally, video RAM
- Storing them in normal memory works but is really slow
- Some computers have unified memory, which is in the middle

So:

- A 9B model will fit on any reasonable gaming PC
- Biggest "gaming" graphics card is the Nvidia RTX 5090, with 32GB of VRAM: up
to 64B models; more realistically 30B models
  - space for context
- A Mac Studio with 512GB of RAM: This can easily run a 300B model at 4bpw or a
600B model at 8bpw.

Past that we're looking at heavy duty servers.

- 4 RTX 6000 = too much money, but ~400GB of VRAM.
- 1TB GDDR5 = can run models up to ~1.5T parameters

Why buy GPU or unified memory? Memory bandwidth

- Inference needs to run the token past every parameter
- 5090 is 1.8 TB / s
  - If we have 30TB model at 4bpw = 15GB of data = 120 tokens/second
- Mac is 1.2 TB/ s
  - If we have 30TB model at 4bpw = 15GB of data = 80 tokens/second
- Desktop PC with 64GB of DDR5
  - That's 100 GB/s = 6 tokens/second

Some models are "Mixture of Experts" and only need to activate some weights.
