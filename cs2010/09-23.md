
# How to use a Computer

Background we've covered:

- We know how text is stored on a computer.
- We know about text files.
- We know about Git.

Here's how to use a computer for productive purposes:

- Create / work with text files.
- We store those text files in Git repositories.

One clear exception: Real-world multimedia

- Pictures
- Sound recordings
- Videos

One less clear exception: Your boss tells you to use specific software /
workflow.

## Git: Why?

- Version tracking (I messed up my project, I want to get back what I had
yesterday)
- Collaboration (Alice is working on the *same* content as Bob, how do they
merge their work together into one thing.)

Setting up git / github: 4 complications

- You need to install git: <https://git-scm.org>
- Initial configuration: Set your name and stuff
- You need to set up a github account
- You need to set up authentication with github
  - Create and add an SSH key
  - OR use the github app
  - OR use repostiory tokens
