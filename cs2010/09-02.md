## Data on Computers

- Basic unit of data: The bit - one piece of data, either 0 or 1
- That makes it easy to distinguish two values:
  - The number 0 from 1
  - off from on
  - true from false
  - 37 from 1382
- We want to be able to store more complex stuff than the distinction
between two possible values
- How? Use more than one bit.

Definition: A byte is 8 bits.

Why 8 bits?

- Convenient to use powers of 2. 8 is 2^3.
- But...

## Storing numbers with bits

- The kind of number I want to talk about first is non-negative integers.
  - 0, 1, 2, 3, 4, 5, 6, 7, ...
- This has a clear start: 0
- So we're going to represent as many of these numbers as we can starting at 0.

- 1 bit lets us represent 2 values: 0 is 0, 1 is 1
- 2 bits lets us represent 4 value:
  - 00 is 0
  - 01 is 1
  - 10 is 2
  - 11 is 3
- 3 bits lets us represent 8 value (it doubles each time we add a bit):
  - That gives us from 000 = 0, up to 111 = 7
- 4 bits lets us represent 16 values
  - That gives us from 0000 = 0, 1111 = 15
- k bits lets us represent 2^k values
  - That gives us from (k zeros) = 0 up to (k ones) = (2^k)-1
- 8 bits (one byte) lets us represent 2^8 values = 256
  - That gives from from 0 up to 255
- 64 bits (one 64-bit word) lets us represent 2^64 values =
  1.8446 x10^19
  - 10^3 ~ 2^10 = thousand / kilo
  - 10^6 ~ 2^20 = million / mega
  - 10^9 ~ 2^30 = billion / giga
  - 10^12 ~ 2^40 = trillion / tera
  - 10^15 ~ 2^50 = quadillion / peta
  - 10^18 ~ 2^60 = quintillion / exa

## Video Representation

- Now we have numbers
- We want 2 hours of video and audio
- We'll make images out of pixels (picture elements)
  - A pixel is three 8-bit numbers: Red, Green, Blue
  - (255, 0, 0) is bright red
  - (0, 0, 0) is black
  - (255, 255, 255) is white
  - (255, 0, 255) bright purple
- 4k display is 3840 x 2160 pixels
- For (movie) video, typically 24 frames / second.
- `3 bytes * 3840 * 2160 pixels * 24 * 60 * 60 * 2`

## Sound

- We sample intensity at 44.1 kHz, or once per 1 / 441000 seconds
- So if you have 100,000 samples, that's 2 seconds of audio. At
16 bits per sample, that'd be about 200 KB of data.

## Text

- Letters, numbers, and keyboard symbols fit in 8 bits (one byte).
- Multiple characters is multiple bytes.
