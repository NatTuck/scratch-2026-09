
# Software Engineering

## Software Engineering?

Engineering is when you use known methods to solve well understood problems.

Software looks nothing like that.

Two cases

1. Someone has already done this.
2. Nobody has done this before. Research, not engineering.

Worse:

1. In software development, typically we don't even know what we want.

## What are we going to look at

- How do deal with writing a large software project.
- How to start when you don't know exactly what you want.
- How to work with a team.
- Procedures and tools to manage this stuff.
